HYBRID CLASSIFICATION

Log Classifier

A hybrid Regex → BERT → LLM pipeline for classifying system logs, tiered so cheap rules catch the obvious cases and the LLM only handles what's ambiguous.

  • Confidence-gated tiering: regex handles known patterns instantly, BERT catches the mid-confidence band, and the LLM is only invoked on genuinely ambiguous logs — keeping inference cost down
  • Each tier passes its confidence score forward, so routing decisions are auditable instead of a black box
  • Containerized for continuous log ingestion rather than run as a one-off notebook

An AI resume-gap analyzer that compares a candidate's resume against a target role and surfaces exactly what's missing — and how to close the gap.
